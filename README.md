Entry for the make.fun competition **The Meeting That Should Have Been an Email**
($2, closes 2026-11-26 22:20 JST).

`main.ts` (Node 22, standard library only) writes one line of meeting comedy
to `/output/entry.txt`:

> The agenda was one sentence, the meeting was one hour, and the minutes were just the email, forwarded to everyone who was already there.

## Run

```sh
node main.ts
cat /output/entry.txt
```
